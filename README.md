# Project-Unicoffe
## Sistema da Cafeteria Unicofe

Desenvolvimento de um sistema web para gerenciamento de pedidos e clientes de uma cafeteria, com foco na implementação de funcionalidades back-end utilizando PHP e MySQL.

O back-end contempla o processamento de cadastros e autenticação de usuários, incluindo login e autenticação em duas etapas (2FA), além da integração com o banco de dados para gerenciamento das informações. O sistema também possui painel administrativo, geração de relatórios e integração com um serviço externo para consulta de CEP.

**Principais funcionalidades:**
- Cadastro e autenticação de usuários.
- Login com autenticação em duas etapas (2FA).
- Gerenciamento de pedidos e clientes.
- Integração e manipulação de dados no MySQL.
- Painel administrativo e geração de relatórios.
- Integração com serviço externo de consulta de CEP.

**Tecnologias utilizadas:** PHP, MySQL, JavaScript, HTML5 e CSS3.
